半山小寺 · 独立版 使用说明
==========================

这个文件夹就是完整的网站，不依赖任何国外网站（3D 引擎、贴图、模型都在里面）。

一、文件夹里有什么
  index.html          网页本体
  assets/             贴图、天空、模型（模型存成了 .js 文件）
  vendor/             3D 引擎 three.js（MIT 开源协议，见 THREE-LICENSE.txt）

二、为什么双击 index.html 打不开
  浏览器出于安全限制，不允许直接从本地文件运行这种 3D 网页，
  必须放到"网站服务器"上，用 http:// 或 https:// 的网址打开。

三、怎么让国内的人用手机打开
  把整个文件夹（保持里面的结构不变）上传到任意一个"静态网站托管"服务，例如：
    - 腾讯云：对象存储 COS 开启"静态网站"，或云开发的"静态网站托管"
    - 阿里云：对象存储 OSS 开启"静态页面"
  上传后平台会给一个网址，发给别人，手机浏览器、微信里点开就能玩。

  注意：
    - 服务器在中国大陆、又想绑定自己的域名的话，需要先做 ICP 备案（只能本人办理）。
    - 部分平台的默认网址有限制（比如不能直接在浏览器里显示网页、只能下载），
      上传前请看清所选平台的说明。

四、在自己电脑上试玩
  电脑装了 Python 的话，在这个文件夹里打开命令行，运行：
    python -m http.server 8000
  然后用浏览器打开 http://localhost:8000

五、素材来源
  材质贴图、天空、石头/灌木/蕨草/茶桌/铜罐模型来自 Poly Haven（polyhaven.com），CC0 公共授权，可商用。
